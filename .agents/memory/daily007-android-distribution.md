name: Daily007 Android distribution
description: The user's requirement for sharing the Android app itself with friends.
---

The user wants a directly transferable, installable Android APK for friends, not a referral URL or a Play Store link.

**Why:** The user explicitly said they want the application itself to send to friends, not a link.

**How to apply:** Distinguish an APK from an invite link, and check current Replit/Expo Android build support before promising or attempting to produce one. A build handoff document is not the APK.
