---
name: Daily007 referral links
description: Product expectations for opening and sharing referral invitations.
---

Referral invites should be directly usable: the shared link is a clickable HTTPS URL that opens signup with the referring code prefilled. In the native app, tapping the invite should try the `daily007://` scheme; sharing should use the HTTPS link. Display a simple, pronounceable five-letter code, and keep previously issued codes valid so existing invites do not break.

**Why:** The user reported referral links were not clickable and referral codes were too long to remember.

**How to apply:** Preserve both public web and native invite paths, accept legacy codes during signup, and keep the existing referral reward policy unchanged.
