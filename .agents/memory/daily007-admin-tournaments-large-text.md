---
name: Admin tournament list large text
description: Native verification of tournament card readability and interactions at enlarged Android text sizes.
---

**Rule:** Preserve the stacked tournament name/status and full-width action layout at font scale 1.5 and above. Keep tournament cards openable and the list scrollable at larger text sizes.

**Why:** The user confirmed on Android that tournament names, statuses, and actions did not overlap at 1.5× or 2×, and that opening a tournament and scrolling still worked. The authenticated Admin screen was not available in the browser preview.

**How to apply:** Recheck the actual Android Admin tournament list at 1.5× and a larger setting after changing its card layout, actions, or font-scale threshold.
