System Specification Prompt for Developer
​Project Overview:
We need to implement a Game Mode registration system behind the home page posters/cards for 3 different game modes: Solo Battle Royale, Squad Battle Royale, and Clash Squad.
​1. Solo Battle Royale
​Capacity: 48 Players (Individual)
​Entry Requirement: Entry fee in Coins (configurable by Admin).
​User Flow & Modal Form:
​When a user clicks the "Solo" poster, open a registration modal.
​Form Fields Required:
​Player Game Name (Text input)
​Game UID (Text/Numeric input)
​Action Button: Pay [X] Coins & Join
​Backend Logic:
​Deduct the entry coins from the user's wallet balance upon confirmation.
​Automatically lock registration once 48 players have joined.
​2. Squad Battle Royale
​Capacity: 48 Players (12 Teams × 4 Players)
​Entry Requirement: Entry fee in Coins (configurable by Admin).
​User Flow & Modal Form:
​When a user clicks the "Squad" poster, open the Team Registration modal.
​Form Fields Required:
​Team Captain Game Name (Text input)
​Captain Game UID (Text/Numeric input)
​Player 2 Name (Text input)
​Player 3 Name (Text input)
​Player 4 Name (Text input)
​Action Button: Pay [X] Coins & Register Team
​Backend Logic:
​The Captain registers and pays on behalf of the team.
​Automatically mark the match as "FULL" once 12 teams (48 players total) are registered.
​3. Clash Squad (4v4)
​Capacity: 8 Players (2 Teams × 4 Players)
​Entry Requirement: Entry fee in Coins (configurable by Admin).
​User Flow & Modal Form:
​When a user clicks the "Clash Squad" poster, open the Registration modal.
​Form Fields Required:
​Team Captain Game Name (Text input)
​Captain Game UID (Text/Numeric input)
​Player 2 Name (Text input)
​Player 3 Name (Text input)
​Player 4 Name (Text input)
​Action Button: Pay [X] Coins & Book Slot
​Backend Logic:
​Once 2 full teams register, close the slot and trigger the match setup.
​4. Admin Panel Controls Required
​Set Entry Coins: Ability to dynamic set or update coin entry fees for each mode/match.
​Room Credentials: Field to input and publish Room ID and Password 10–15 minutes before match start (visible only to registered players).
​Export Player List: Ability for Admin to view and download player names and UIDs for match room creation.
