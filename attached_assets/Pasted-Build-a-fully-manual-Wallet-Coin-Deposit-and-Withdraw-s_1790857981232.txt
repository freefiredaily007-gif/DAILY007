Build a fully manual Wallet / Coin Deposit and Withdraw system for my gaming tournament application.

IMPORTANT:

- Do NOT integrate any third-party payment gateway.
- Do NOT use automatic UPI verification.
- Do NOT use bank API, UPI API, PhonePe API, Google Pay API, Razorpay, Cashfree, PayU, Stripe or any other payment provider.
- There must be NO automatic payment verification.
- Everything must be handled manually by the admin.

USER WALLET – ADD COINS

Create an "Add Coins" section inside the user's Wallet.

When the user clicks "Add Coins":

1. Show my fixed UPI ID prominently.
   
   - Admin can set/change this UPI ID from Admin Panel.
   - User can tap a "Copy UPI ID" button.
   - The UPI ID is only displayed for the user to manually copy.
   - No verification or automatic payment detection is required.

2. Show my UPI QR scanner image.
   
   - Admin can upload/change the QR image from Admin Panel.
   - User can scan it using another UPI/payment application.
   - Do NOT verify the QR payment automatically.

3. Show clear instructions:

"Copy the UPI ID or scan the QR code and make the payment using your preferred UPI application. After completing the payment, return to this app and submit your Transaction ID and Coin Amount. Coins will be added only after Admin manually verifies and approves your payment."

4. After payment, show a form:

- Coin Amount
- Transaction ID / UTR Number
- Optional Payment Screenshot
- Submit Request button

5. When the user submits:
   
   - Create a pending coin deposit request.
   - Do NOT add coins immediately.
   - Change the request status to "Pending Admin Approval".
   - Disable/restrict duplicate submission for the same request.
   - Show the request in the user's transaction history.

6. User should see:
   
   - Requested Coins
   - Transaction ID
   - Date & Time
   - Status:
     - Pending
     - Approved
     - Rejected

ADMIN PANEL – COIN DEPOSIT APPROVAL

Create a "Coin Deposit Requests" section in Admin Panel.

Admin should see every pending request with:

- User Name
- User ID
- Coin Amount
- Transaction ID / UTR
- Payment Screenshot, if uploaded
- Request Date & Time
- Current Status

Admin buttons:

- APPROVE
- REJECT

When Admin clicks APPROVE:

- Add the requested coin amount to that user's wallet balance.
- Mark the request as "Approved".
- Record approval date/time.
- Create a wallet transaction record.
- Show the updated balance to the user.
- Send an in-app notification:
  "Your coin deposit has been approved. Coins have been added to your wallet."

When Admin clicks REJECT:

- Do NOT add coins.
- Mark request as "Rejected".
- Record rejection date/time.
- Send an in-app notification:
  "Your coin deposit request was rejected."

IMPORTANT:
Admin approval must be the ONLY way coins are added from manual UPI deposits.

WALLET BALANCE

User Wallet should display:

- Available Coins
- Pending Deposits
- Total Deposited
- Total Withdrawn
- Transaction History

Every wallet balance change must create a transaction record.

Never directly modify the user's wallet balance without creating a corresponding transaction record.

WITHDRAW SYSTEM

Create a manual withdrawal system.

When user clicks "Withdraw":

Show:

- Coins to Withdraw
- User's UPI ID
- Submit Withdrawal Request

The user's UPI ID here is ONLY information entered by the user for receiving the payout. It is NOT connected to any API and does NOT require verification.

Before submitting:

- Check that the user has enough available coins.
- Reserve/deduct the requested coins according to the application's withdrawal rules so the same coins cannot be withdrawn twice.
- Create a "Pending Withdrawal" request.

Admin Panel should have "Withdrawal Requests".

Admin can see:

- User Name
- User ID
- UPI ID
- Coin Amount
- Equivalent payout amount, if configured
- Request Date & Time
- Status

Admin buttons:

- APPROVE
- REJECT

When Admin approves:

- Mark withdrawal as "Approved/Paid".
- Record admin approval time.
- Record the payout manually outside the application.
- Create a wallet transaction record.
- Notify the user.

When Admin rejects:

- Mark it as "Rejected".
- Return/reserve the coins back to the user's available wallet balance.
- Create a reversal transaction.
- Notify the user.

IMPORTANT:
There must be NO automatic withdrawal/payment processing.

ADMIN SETTINGS

Create an Admin Wallet/Payment Settings section where Admin can manually configure:

- My UPI ID
- UPI QR Scanner Image
- Coin-to-money conversion rate
- Minimum deposit coins
- Maximum deposit coins
- Minimum withdrawal coins
- Maximum withdrawal coins
- Withdrawal enabled/disabled
- Deposit enabled/disabled

Changes made by Admin should immediately reflect in the user Wallet section.

SECURITY & DATA RULES

- Users cannot approve their own deposits.
- Users cannot manually increase their own wallet balance.
- Users cannot edit an already submitted Transaction ID or coin amount after submission.
- Prevent duplicate deposit requests.
- Prevent duplicate withdrawal requests.
- Maintain complete wallet ledger/history.
- Use server-side validation for all wallet balance changes.
- Admin-only operations must be protected by proper admin authentication.
- Never trust the coin amount sent directly from the client when approving a transaction.
- Wallet balance must be calculated and updated securely on the backend/database.

SIMPLE USER FLOW

User:

Wallet → Add Coins → Copy my UPI ID OR Scan my QR → Pay using another UPI app → Return to my app → Enter Transaction ID + Coin Amount → Submit → Pending → Admin manually checks payment → Admin Approves → Coins added.

There is NO automatic verification anywhere.

SIMPLE ADMIN FLOW

Admin Panel → Coin Deposit Requests → Check Transaction ID / Screenshot / Payment manually → Approve → Coins automatically credited inside my application's wallet.

The "automatic" part is ONLY the internal wallet credit after the Admin presses APPROVE. Payment verification itself remains completely manual.

Build this as a clean, reliable, gaming-style wallet system and make sure the entire flow works end-to-end without any third-party payment service.
